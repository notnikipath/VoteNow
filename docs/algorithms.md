# Algorithms

## Anti-fraud

- Captcha token check for public submit requests
- Per-IP hourly submission threshold
- Duplicate fingerprint by respondent ID, email, phone, or IP fallback

## Verification

- Optional invited-list restriction
- SMS or email one-time code request and confirmation
- Tokenized validation in submit workflow

## Analytics

- Live counters for all question types
- Rating average aggregation
- Open text sentiment split
- Tournament winner leaderboard
- Turnout projection by elapsed-time trend

## Export

- Celery task queue for report generation
- Excel workbook generation with tabular snapshots
- PDF report generation with question-level details
